# ReelBox

A TV show tracker built with Next.js 14, Tailwind CSS, and the TVMaze API. Browse, search, and keep track of your favorite shows with a personal watchlist and episode progress tracking.

## Features

- **Search** — Find any TV show with instant debounced search
- **Show Details** — View ratings, genres, status, cast, and episode guides
- **Schedule** — See what's airing today on US networks
- **Watchlist** — Save shows and track your watch progress with localStorage

## Tech Stack

- Next.js 14 (static export)
- Tailwind CSS
- TanStack React Query
- TVMaze API (no key required)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to use the app.

## Build

```bash
npm run build
```

Produces a static export in the `out/` directory.
